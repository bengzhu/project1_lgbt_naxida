# v1.93 Speech 取消重试竞态收口

## 目标

修复 Apple Speech 文件识别、实时麦克风授权和识别后模型翻译在取消/立即重试时的旧回调污染。所有异步回调与 `await` 恢复点必须由当前 Speech run ID 和 Task cancellation 共同隔离。

建议分支：`codeb/v1.93-speech-run-cancellation`，base 必须是最新 `origin/smalldata_test`，不得触碰 `main`。

## 实现要求

- `TranslationSessionStore` 持有 Speech 翻译 Task；取消先 invalidate run ID，再取消 recognition / translation Task，清理引用并回到 idle。
- 新 Speech run 在生成新 run ID 前取消并清空旧翻译 Task。
- `requestMicrophoneAccess()` 返回后复验 run ID 与 capture request，旧授权结果不得启动录音或写失败状态。
- 文件识别后的模型翻译在 `await` 后、写 transcript/state/error 前复验 run ID；summary 回写也必须复验。
- 实时语音翻译使用同一所有权原则，旧翻译不得写 `proLiveTranslationText`、transcript 或状态。
- 文件和实时语音两条路径的 `.translating` 状态都必须可取消。
- Speech contract 作为独立 CI step 只运行一次，并作为 failure summary 与 fail-job 的硬门控。

## 非目标

- 不更换 Apple Speech、GGUF 或翻译模型。
- 不引入第三方 ASR，不调整语言包或识别参数。
- 不修改漫画 OCR、Koharu artifact、翻译质量 gate、覆盖渲染或既有漫画指标。
- 不把静态源码契约或 GitHub-hosted simulator 冒充真机权限、麦克风或 WER/CER 证据。

## 云端验收

- PR base=`smalldata_test`，head=`codeb/v1.93-speech-run-cancellation`。
- manifest 的 branch、commitSha、runId、runAttempt、workflowName 与候选 HEAD 精确一致。
- `xcodeBuildRequired=true`，Xcode build success，`.xcresult`、`xcodebuild.log`、`junit.xml`、`ci-failure-summary.md` 可用。
- Speech contract outcome success，独立日志显示全部测试通过，JUnit 中独立 testcase success。
- UI evidence outcome success；至少查看音频页 compact / Dynamic Type 证据，确认取消按钮不与浮动 Tab 或内容重叠。
- `probe_mode=skip` 可接受，因为本轮不改漫画路径；不得用该 run 声称 Koharu 或语音识别质量改善。

## 禁止项

- 禁止只增加 guard 字符串数量而不验证其位于对应 `await` 与共享状态写入之间。
- 禁止取消后由旧 Task 的 defer 把新 run 的 `isProcessing` 清零。
- 禁止旧翻译把 transcript、summary、错误或成功状态写回新 run。
- 禁止因 Speech contract 已在独立 step 执行而继续在 static checks 重复运行。
- 禁止在没有固定音频语料、参考 transcript 和真机/自托管环境时宣称 WER/CER 或 AI 语音质量提升。
