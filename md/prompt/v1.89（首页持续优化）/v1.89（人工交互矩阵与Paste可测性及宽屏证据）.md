## 4. 交付细则

### 4.1 人工交互矩阵（P0）

在 `md/test/test.md` 写清至少这些用例与期望：

| ID | 场景 | 期望 |
|---|---|---|
| M1 | 空剪贴板点粘贴 | 已有输入保留，不崩，不自动翻译 |
| M2 | 空输入 + 有文本剪贴板 | 填入，状态仍等待翻译 |
| M3 | 非空输入再粘贴 | 换行追加，不覆盖 |
| M4 | 键盘 Done | 一次点击收起 |
| M5 | 点翻译 | 先失焦再 submitDraft |
| M6 | VoiceOver | 粘贴/翻译/交换/完成可读 |
| M7 | 标准字号键盘关闭 | 首屏见中文粘贴+翻译，无固定 48pt 净空 |
| M8 | XXL/AX 或聚焦 | 48pt 净空，Tab 不遮挡 |

矩阵必须声明：CI 截图不能替代 M1–M6 的人工点击；Agent C 验收时若无人工证据，只能记遗留，不能谎称已验证。

### 4.2 Paste 可测性（P0/P1）

优先顺序：

1. DEBUG-only launch argument / env，例如 `-ui-test-paste-text` 或 `AITRANS_UI_TEST_PASTE_TEXT`，仅当 **用户点击粘贴** 时若系统 payload 为空且 DEBUG 注入存在，则使用注入文本（或并行提供可访问的 debug 辅助按钮，默认隐藏）。
2. 静态契约断言：release 路径无注入符号；DEBUG 注入不在 lifecycle 自动触发。
3. 文档写明 XCUITest 在 iOS 26.x 上系统 PasteButton 剪贴板隔离的已知限制。

### 4.3 宽屏证据（P0）

- `capture-ui-evidence.sh` 至少新增 1 张 iPad 或 iPhone 横屏文本首页运行态证据。
- manifest 记录 device / orientation / Dynamic Type / commitSha。
- CI 对 `codeb/v1.89-*` 强制 evidence；失败阻塞。
