## 当前判断
v1.35 已把 BubbleIndex majority mask、safe area、same-bubble sibling 和 split 风险收成账本；v1.36 已在 rounded-rect BubbleMask proxy 上复刻 distance-field safe pixels / maximum safe rect。它们解决的是“已归属气泡内部是否有可解释安全区”的问题。

但 Koharu 的真实 BubbleMask 不是 bbox inset 或 rounded-rect proxy，而是实例 ID mask。当前 AITRANS 仍缺一个关键诊断层：当多个气泡相邻、重叠或一个 proxy bubble 过大时，哪些气泡 / 子气泡 / block 之间存在可切分的 seam，哪些只是同气泡 sibling layout，哪些必须等待真实 BubbleMask artifact。当前已有 `bubbleSplitCandidateReport.parentBubbleIDs = [4, 6, 7]`、`bubbleMaskReport.inconsistentBubbleAssignmentBlocks = [4, 5, 11, 12]`、`bubbleAssignmentCorrectionReport.recommendedCorrectionBlocks = [5, 11]`，但缺少 Koharu 式实例边界邻接图和切缝证据账本。

v1.37 应新增一个 report-only 的 `Koharu Bubble Adjacency Seam Shadow Report`：

- 继续只使用 AITRANS 自己已有的 BubbleMask rounded-rect proxy、BubbleIndex / DistanceField / split candidate / sibling / render lock / OCR damage 证据。
- 构建 bubble adjacency graph，记录相邻 bubble / overlap / gap / mask touch / bbox corridor / shared seam risk。
- 对 oversized parent bubbles、split candidates 和 same-bubble sibling groups 生成 seam candidate ledger，解释“这里像真实 BubbleMask 应该拆成多个实例”还是“只是同气泡多块排版”。
- 对每个 block 输出 seam-aware assignment / split risk / OCR damage / render risk 归因，帮助后续决定是否值得请求真实 BubbleMask 或开独立 split shadow 执行任务。
- 与 convergence 联动，新增 v1.37 reference report、work item 和 gate。

本轮是 Koharu `BubbleMask.instanceID -> BubbleIndex majority assignment -> seam / adjacency` 的算法结构复刻评估，不是 OCR 提升版本。报告只给证据，不改变主流程。

## Bubble pair ledger 要求
`pairLedgers[]` 只记录有邻接意义的 bubble pair，避免全量 N^2 噪声。候选 pair 来源：

- bbox 相交或 expanded bbox 相交；
- 两个 bubble 的最小 gap 小于阈值，例如 `max(8, min(width,height)*0.04)`；
- 两个 bubble 共享 split candidate / sibling group / assignment conflict block；
- DistanceField 或 BubbleIndex 报告标出 safe-area / sibling 风险。

每条至少包含：

- `pairID`
- `bubbleAID`
- `bubbleBID`
- `bubbleABBox`
- `bubbleBBBox`
- `bboxOverlapArea`
- `bboxGapPx`
- `expandedBBoxIntersects`
- `proxyMaskTouching`
- `proxyMaskMinimumGapPx`
- `sharedBlockIndexes`
- `sameBubbleSiblingGroupIDs`
- `splitCandidateIDs`
- `distanceFieldSafeRectConflict`
- `renderLockInvolved`
- `pairVerdict`
- `nextAction`
- `decisionSignals`
- `evaluationSignals`
- `groundTruthUsedForDecision = false`
- `wouldChangeMainFlow = false`
- `diagnosticOnly = true`

稳定 `pairVerdict` 建议：

- `independentBubbles`
- `adjacentButSeparated`
- `touchingProxyMasks`
- `overlappingProxyBBoxes`
- `sameParentSplitCandidate`
- `siblingLayoutOnly`
- `needsRealBubbleMask`
- `manualReviewOnly`

注意：`proxyMaskTouching` / `proxyMaskMinimumGapPx` 可以在 rounded-rect proxy ID mask 上近似计算；如果实现成本高，可以先用 bbox gap + expanded intersection，并明确 `maskGapAlgorithm = "bboxFallback"`，但 gate 要 warning。

稳定 `seamCandidateVerdict` 建议：

- `reportOnlySeamCandidate`
- `siblingLayoutNoSplit`
- `splitCandidateNeedsRealBubbleMask`
- `assignmentConflictNeedsReview`
- `distanceFieldSupportsCurrentLayout`
- `distanceFieldTooSmallForSplit`
- `renderLockedNoSplit`
- `manualReviewOnly`

算法建议：

1. 对同一 parent bubble 内的 block center 做 x / y 投影，寻找最大空隙作为候选 seam。
2. 若有 `bubbleSplitCandidateReport` 的 candidate bbox，优先用 candidate seed blocks 和 bbox 估计 seam orientation。
3. 若 same-bubble sibling 的 current safe rect 已稳定且 overlap 很低，标为 `siblingLayoutNoSplit`，不要误导为需要拆气泡。
4. 若 DistanceField safe rect / current safe rect 显示多个 block 共享区域过小或重叠风险高，标为 split review，但仍只 report-only。
5. 所有 score 只能使用 bbox、bubbleID、split candidate、safe rect、render lock、OCR damage 等无真值信号。
