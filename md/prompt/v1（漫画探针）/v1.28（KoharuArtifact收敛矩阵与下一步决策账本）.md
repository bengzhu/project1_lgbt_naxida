## 本轮目标
从最新 `smalldata_test` 开分支：

```text
codeb/v1.28-koharu-artifact-convergence
```

新增一个 AITRANS 自有探针驱动的 Koharu artifact 收敛报告：

```text
koharuArtifactConvergenceReport
```

报告目标：

1. 聚合 `koharuArtifactDAGReport`、`koharuStageGapReplicationReport`、`koharuNativeReplicationScoreboardReport`、`nativeTextBoxProxyLedgerReport`、`bubbleMaskAssignmentSplitScoreboardReport`、`segmentMaskProxyCoverageScoreboardReport`、`externalArtifactReadinessReport`、`externalTextBoxShadowOCRReport`、`cleanTextDiagnostic`、`diagnostics` 和最终 `blocks`。
2. 输出 Koharu canonical artifact 维度的 convergence matrix：`SourceImage`、`ContentCrop`、`TextBoxes`、`BubbleMask`、`SegmentMask`、`OcrText`、`Translations`、`Inpainted` / glyph erase proxy、`RenderedSprites`、`FinalRender`。
3. 输出逐块 artifact path：每块当前 first blocking artifact、primary structural bottleneck、translation model floor 状态、render lock 状态、是否需要真实 external artifact、下一步 action。
4. 输出 work item closure ledger：标记 v1.25 / v1.26 / v1.27 三个 work item 已由对应 report 执行，未闭合项集中到 `WI-translation-model-floor-comparison`、`WI-render-regression-lock` 和 `WI-external-artifact-optional-handoff`，但本轮不实际改 prompt、模型、渲染或 external artifact。
5. 输出 gate ledger，证明本报告只做诊断收敛，不新增 OCR / LLM，不改变主流程。

本轮仍是 report-only / diagnostic-only。不得改变主 OCR、翻译输入、覆盖图、`blockPassed`、失败分类、post-fusion cleanup、候选选择、`configuration.currentBlockSource`、`safeLayoutRect`、`glyphMaskFillRects`、背景填充行为、`textRegionCropReport.adoptedCount` 或 `metrics/version_history.csv` 口径。

## 目标 2：Stage Convergence Matrix
新增 `stages[]`，每个 Koharu canonical artifact 一条。

每条至少输出：

- `stageName`
- `referenceKoharuArtifact`
- `currentAITRANSArtifact`
- `convergenceStatus`
- `proxyOnly`
- `realArtifactAvailable`
- `sourceReports`
- `decisionSignals`
- `evaluationSignals`
- `affectedBlocks`
- `firstBlockingArtifact`
- `closedByWorkItems`
- `blockedByWorkItems`
- `primaryNextAction`
- `mustNotPromoteReasons`
- `groundTruthUsedForDecision = false`
- `diagnosticOnly = true`
- `wouldChangeMainFlow = false`

建议 stage 映射：

- `SourceImage` / `ContentCrop`：`nativeReady`，由固定 `test/1.png` 和内容裁切证明。
- `TextBoxes`：来自 `nativeTextBoxProxyLedgerReport`，通常为 `proxyStableReportOnly` 或 `stopLocalTuning`。
- `BubbleMask`：来自 `bubbleMaskAssignmentSplitScoreboardReport`，通常为 `proxyStableReportOnly` / `proxyBlocked` / `requiresRealArtifact`。
- `SegmentMask`：来自 `segmentMaskProxyCoverageScoreboardReport`，必须保留 `proxyOnly = true`。
- `OcrText`：来自 `diagnostics`、OCR similarity、`failureCategory`、TextBox ledger stoplist；不要用 ground truth 决定 nextAction，只可放 evaluationSignals。
- `Translations`：来自 `cleanTextDiagnostic.passRate` 和 `translationFailureBreakdown`；若 clean text pass rate 仍低，标记 `modelLimited`，避免把所有失败都归咎 OCR。
- `Inpainted` / glyph erase proxy：来自 SegmentMask proxy cleanup ledger 和 background fill guardrail，必须说明 `inpaintingImplemented = false`。
- `RenderedSprites` / `FinalRender`：来自 render collision、failure overlay、PNG 存在性和 no-overflow 证据；当前若无 overflow/truncation，应标记 `renderStableLocked`。
- `ExternalArtifacts`：来自 readiness gate；当前缺真实 active artifact 时标记 `externalOptionalMissing`，不阻塞 native convergence report。
