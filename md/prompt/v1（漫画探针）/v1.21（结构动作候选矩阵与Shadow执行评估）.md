## 目标 1：生成结构动作候选矩阵
为每个最终 block 根据 v1.20 风险和动作建议生成 0..N 个候选。候选必须是结构动作，不是任意 OCR/prompt 试参。

建议候选类型稳定字符串：

- `readingOrderReindex`
- `bubbleAssignmentReview`
- `bubbleSplitShadow`
- `sameBubbleSiblingLayout`
- `duplicateFragmentProtection`
- `textBoxEvidenceRequired`
- `segmentMaskEvidenceRequired`
- `renderSafeAreaReflow`
- `manualReviewOnly`

每个候选至少输出：

- `candidateID`
- `blockIndex`
- `candidateType`
- `sourceRecommendedAction`
- `sourceRisks`
- `inputSignals`
- `plannedOperation`
- `expectedBenefit`
- `executionMode`
- `diagnosticOnly = true`
- `groundTruthUsedForPlanning = false`
- `wouldChangeMainFlow = false`
- `mustNotPromoteReasons`

`plannedOperation` 应描述具体可执行动作，例如：

- 仅计算 proposed order，不改变 `blocks` 数组。
- 使用 `correctedBubbleID` 或 `maskDominantBubbleID` 生成 shadow regroup，不改变主 bubbleID。
- 使用 `bubbleSplitCandidate` / subRegion / maskSafeRect 生成 shadow safe layout，不改变主 safeLayoutRect。
- 对 protected key dialogue / decorative 标题加删除保护，不改变 post-fusion cleanup。
- 对 TextBox / SegmentMask 证据不足块标记 `needsRealArtifact`，不伪造 detector 输出。

## 目标 2：执行轻量 Shadow 评估
本轮要比 v1.20 更“可执行”：至少对候选做可计算的 shadow 评估，而不是只列建议。执行范围应轻量，适合 `ci-fast`。

每个候选输出：

- `executed`
- `executionSkippedReason`
- `shadowMetrics`
- `controlMetrics`
- `delta`
- `promotionVerdict`
- `promotionBlockers`
- `recommendedNextStep`

建议 `shadowMetrics` / `controlMetrics` 包含：

- `orderIndexDelta`
- `bubbleIDBefore`
- `bubbleIDAfter`
- `bubbleConsistencyBefore`
- `bubbleConsistencyAfter`
- `maskCoverageBefore`
- `maskCoverageAfter`
- `safeLayoutAreaBefore`
- `safeLayoutAreaAfter`
- `renderOverflowBefore`
- `renderOverflowAfter`
- `siblingOverlapBefore`
- `siblingOverlapAfter`
- `ocrSimilarityBefore`
- `ocrSimilarityAfter`
- `translationFailureCategoryBefore`
- `translationFailureCategoryAfter`

注意：

- `ocrSimilarityAfter` 只能用于评估已有 shadow OCR 结果，例如 crop / line / external shadow 已经产出的候选；不要为了本轮在 `ci-fast` 中新增昂贵 OCR 扫描。
- `translationFailureCategoryAfter` 只能在已有 report-only 翻译对照存在时填写；不要扩大 LLM 调用量。
- 对 render safe-area 类候选，可以只做几何和离屏碰撞复算，不新增 OCR / LLM。
- 对缺真实 external artifacts 的块，必须输出 `executed = false`、`executionSkippedReason = missingRealArtifacts` 或 `needsRealArtifact`，不能用 internal proxy 冒充真实 TextBoxes / BubbleMask / SegmentMask。

建议 `promotionVerdict` 稳定字符串：

- `reportOnlyWouldImprove`
- `reportOnlyNoBenefit`
- `blockedByOCRRegression`
- `blockedByBubbleConflict`
- `blockedByWeakTextBoxEvidence`
- `blockedByWeakSegmentMaskEvidence`
- `blockedByProtectedText`
- `blockedByMissingRealArtifact`
- `manualReviewOnly`

## 实现建议
建议在现有模式内小步实现：

1. 在 `TranscriptModels.swift` 新增 `MangaStructureActionCandidateReport`、case、candidate、metric/delta 结构。
2. 在 `MangaOverlayProbeReport` 顶层新增 `structureActionCandidateReport`。

4. 候选生成优先使用已有 report 的字段，不新增 heavy image OCR / LLM 调用。
5. 在 `MangaOverlayProbeService` 的 TXT 输出中添加报告级和逐块摘要。
6. 只在 `ci-fast` 可承受范围内做几何复算；`full` 可以写更多已存在 shadow 字段，但不要引入必须 full 才可见的核心字段。

结构上建议保持：

```text
readingOrderStructureAuditReport
  -> structureActionCandidateReport
      -> candidates per block
      -> shadow metrics / control metrics
      -> promotion verdict / blockers / next step
```
