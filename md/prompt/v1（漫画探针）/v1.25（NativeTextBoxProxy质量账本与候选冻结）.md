## 本轮目标
从最新 `smalldata_test` 开分支：

```text
codeb/v1.25-native-textbox-proxy-ledger
```

新增一个 AITRANS 自有探针驱动的 Native TextBox proxy 质量账本：

```text
nativeTextBoxProxyLedgerReport
```

报告目标：

1. 执行 v1.24 的 P0 work item：`WI-native-textbox-artifact-scorecard`。
2. 把现有 `textRegionCropReport`、`preCropTextBoxPlanReport`、`cropExperimentReport`、`textBoxPlanFailureReport`、`lineTextBoxPlanReport`、`lineCropExperimentReport`、`bubbleMaskReport`、`segmentMaskReport`、`ocrCharacterDamageAuditReport`、`internalStructureBottleneckReport` 和 v1.24 scoreboard 的 block scorecard 合并成一个 TextBox proxy 质量账本。

5. 把 ground-truth-free 决策信号和 evaluation-only ground truth 指标严格分离，避免用 `test/1.ground_truth.json` 做候选选择、排序、冻结或晋级。

本轮仍是 report-only / diagnostic-only。不得改变主 OCR、翻译输入、覆盖图、`blockPassed`、失败分类、post-fusion cleanup、候选选择、`configuration.currentBlockSource` 或 `metrics/version_history.csv` 口径。

新增 `blockLedgers[]`，每个最终块一条，数量必须等于 `totalBlocksDetected`。

每条至少输出：

- `blockIndex`
- `bubbleID`
- `failureCategory`
- `blockPassed`
- `qualityStatus`
- `primaryFreezeReason`
- `candidateSources`
- `candidateCount`
- `bestReportOnlyCandidateID`
- `rawWordPreservationStatus`
- `protectedKeywordStatus`
- `wordOrderStatus`
- `bubbleConstraintStatus`
- `segmentMaskConstraintStatus`
- `ocrDamageStatus`
- `translationModelFloorStatus`
- `renderStatus`
- `stoplistHit`
- `stoplistReasons`
- `decisionSignals`
- `evaluationSignals`
- `mustNotPromoteReasons`
- `nextAction`
- `groundTruthUsedForDecision = false`
- `diagnosticOnly = true`
- `wouldChangeMainFlow = false`

`decisionSignals[]` 只能来自无真值证据，例如：

- `failureCategory`
- `textRegionCropReport.rejectedCount / adoptedCount`
- `textBoxPlanFailureReport.blockSummaries[].promotionBlockers`
- `lineCropExperimentReport.blockSummaries[].stopReasons`
- `lineCropExperimentReport.stoppedAfterLineResearchBlocks`
- `bubbleMaskReport.blockDiagnostics[].dominantBubbleID / coverage`
- `bubbleMaskReport.inconsistentBubbleAssignmentBlocks`
- `segmentMaskReport.diagnostics[].glyphEscapesBubble / usableForCropEvidence / weak`

- `internalStructureBottleneckReport.blockSummaries[].primaryBottleneck`
- `koharuNativeReplicationScoreboardReport.blockScorecards[].stopEvidence / recommendedWorkItemID`
- `cleanTextDiagnostic.passRate`

`evaluationSignals[]` 可以包含真值指标，但必须标记 evaluation-only，例如：

- `ocrGroundTruthSimilarity`
- `bestGroundTruthType`
- `groundTruthMatch`
- `wordOrderPreserved`

不得用 `ocrGroundTruthSimilarity` 决定 `qualityStatus`、`bestReportOnlyCandidateID`、`primaryFreezeReason`、`nextAction` 或任何排序。
