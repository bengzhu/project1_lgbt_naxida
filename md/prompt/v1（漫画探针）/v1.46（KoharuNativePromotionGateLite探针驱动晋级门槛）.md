```text

  -> detector-lite shadow OCR / refinement shadow OCR
  -> closed-loop router
  -> BubbleMask instance-lite
  -> SegmentMask refinement-lite
  -> Native Artifact Bundle-Lite
```

v1.45 已把 TextBox / BubbleMask / SegmentMask / OCR / Translation / Render 的 native-lite 证据汇成每块 bundle 和 consistency edges。下一步不应继续只堆一个平行报告，也不应把 proxy 直接接入主流程；更合适的是建立一个可验收的 `promotion gate`，用 AITRANS 自己的探针输出回答：

1. 哪些 native-lite bundle 只是诊断稳定，仍不能晋级。
2. 哪些块理论上可进入后续 full-probe shadow 复核。
3. 哪些块应停止几何调参，因为瓶颈是模型地板或渲染锁。
4. 哪些块必须等待真实 TextBoxes / BubbleMask / SegmentMask，而不是继续调 Vision crop。
5. 若未来要把 native-lite artifact 导出为 active candidate，需要满足哪些机器可检 gate。

本轮仍是 report-only 的算法结构门槛层，不做主流程替换。

报告目标：

1. 在漫画探针中新增一个 report-only Koharu native promotion gate 阶段，执行顺序建议在 `koharuNativeArtifactBundleLiteReport` 之后、最终 `koharuArtifactConvergenceReport` refresh 之前。
2. 只消费当前探针 runtime 内存里的 final blocks、diagnostics、v1.39-v1.45 native-lite reports、Render Regression Lock、RenderSprite Fit、Translation Model Floor、external artifact readiness 和 clean text diagnostic。
3. 不新增 OCR 调用，不新增 LLM 调用，不新增 PNG，不读旧 `output/` 决定本轮 route。
4. 为每个 final block 输出 `promotionLedger`：TextBoxes / BubbleMask / SegmentMask / OcrText / Translations / RenderedSprites / FinalRender 的晋级状态、阻塞原因、证据来源、禁止晋级原因和下一步。
5. 输出 stage-level `promotionStageGates`：每个 Koharu artifact 阶段是否 `shadowReviewEligible`、`blockedByProxyEvidence`、`blockedByModelFloor`、`blockedByRenderLock`、`blockedByMissingRealArtifact`、`stopLocalTuning` 或 `reportOnlyStable`。
6. 输出 `nativeCandidateExportPreview`：只做 JSON 报告中的预览清单，列出如果未来要导出 AITRANS-native candidate artifact，需要的 TextBox / Bubble / Segment 字段、来源、bbox、风险和必须通过的 validator；本轮不得创建、写入或修改 `test/koharu_artifacts/`。
7. 输出 probe-driven bottleneck summary：按 OCR 准确率趋势、气泡归属 / 分割、翻译失败分类、覆盖渲染、结构一致性五类聚合阻塞原因。
8. ground truth 只能进入 `evaluationSignals`，例如 OCR 相似度、核心 / 装饰类型、人工真值匹配状态和质量趋势；禁止用于 promotion eligibility、stage gate、candidate preview、route、nextAction 或 worklist。
9. `koharuArtifactConvergenceReport.referenceReports`、`workItemLedger` 和 `gateLedger` 必须联动 v1.46。
10. `1_ocr_probe_text.txt` 必须新增 report summary、逐块 promotion ledger、stage gate、candidate export preview 和 convergence v1.46 work item / gate 摘要。
