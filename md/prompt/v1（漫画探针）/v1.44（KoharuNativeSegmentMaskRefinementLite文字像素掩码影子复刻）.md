v1.39-v1.43 已形成两条 native 影子复刻线：

- TextBoxes / OcrText 侧：v1.39 detector-lite -> v1.40 shadow OCR -> v1.41 refinement shadow OCR -> v1.42 closed-loop router。
- BubbleMask / BubbleIndex 侧：v1.35 BubbleIndex -> v1.36 DistanceField -> v1.37 seam -> v1.38 RenderSprite fit -> v1.43 native BubbleMask instance-lite。

下一步不应重开 v17-v20 已证伪的 crop / line / deskew 调参路线，也不应更换模型。Koharu 源码和 `md/koharu研究/v1.38-current-gap-to-koharu.md` 都说明，`SegmentMask` 是 TextBoxes 和 BubbleMask 之间的关键结构层：Koharu 的文字像素 mask 不是全图阈值结果，而是被 TextBoxes 扩张框严格约束；没有 TextBoxes 时 mask 会被清空，避免把背景线条、气泡边缘和角色轮廓误当成文字。

AITRANS 当前已有 `segmentMaskReport`、glyph mask、`segmentMaskProxyCoverageScoreboardReport` 和渲染用 `glyphMaskFillRects`，但它们还不是 Koharu 式 `TextBoxes -> constrained SegmentMask` 阶段。v1.44 要新增 `koharuNativeSegmentMaskRefinementLiteReport`：只用源图像像素、detector-lite TextBox 候选、final blocks、v1.43 instance-lite BubbleMask、现有 glyph / SegmentMask proxy、render lock 和翻译失败分类，生成 TextBox 约束的文字像素 mask refinement 账本。

这是 AITRANS 本地算法复刻的一步：让 SegmentMask 从“已有 glyph/proxy 诊断”推进到“受 TextBoxes 和 BubbleMask 约束的源像素文字掩码影子产物”。本轮仍不得替换主 OCR、翻译输入、覆盖图或清字逻辑。

### 2. SegmentMask refinement-lite 算法要求
实现位置建议沿用 v1.43 风格，在 `MangaOverlayProbeService` 或 `TranslationSessionStore` 的私有 helper 中生成报告，不要把逻辑塞进 UI。

最低算法要求：

1. 读取 source image pixel buffer，严格使用现有 content crop，不能把浏览器 UI、广告或底部导航纳入 mask 生成。
2. 选择 TextBox constraints 时优先使用 v1.39 detector-lite candidates；没有可用 candidate 时可以退到 final block bbox 作为 `fallbackFinalBlockBBoxConstraint`，但报告必须把 fallback 标出来，且不得称为真实 Koharu TextBoxes。
3. TextBox 扩张规则要模拟 Koharu 思路：按 bbox 尺寸和 direction hint 给小幅 padding，横排 y padding 大于 x padding，竖排 x padding 大于 y padding；所有 rect 必须 clamp 到 image bounds。
4. 只在 TextBox expanded rect 内提取候选文字像素。建议结合亮度低、局部对比高、饱和度/边缘、与既有 glyph mask / segment proxy 重叠等无真值信号。
5. 对候选像素做连通域过滤：过滤太小噪声、太大背景/线条、长宽比异常、明显气泡边缘或角色轮廓。
6. 若 v1.43 instance-lite majority ID 可用，则候选 glyph 像素必须被所属 instance-lite / current bubble geometry 约束；没有可用 BubbleMask 时标记 `bubbleConstraintFallback`，不得静默通过。
7. refinement 后输出 raw pixel count、afterTextBoxClampPixelCount、afterBubbleClampPixelCount、componentCount、largestComponentArea、maskBBox、maskFillRatio、textboxCoverage、bubbleCoverage、existingGlyphOverlap、segmentProxyAgreement。
8. 本轮不需要持久化真实 mask PNG，但 JSON / TXT 必须有足够统计，让 Agent C 能判断它不是纯 bbox 复制。
