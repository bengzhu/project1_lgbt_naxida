## 当前判断
v1.34 已新增 `koharuNativeAlgorithmReplayMatrixReport`，把 resolver、router、request packet、convergence、TextBox / BubbleMask / SegmentMask scoreboards、translation floor 和 render lock 聚合成 Koharu 本地算法复刻候选矩阵。它解决的是“下一步候选队列和阻塞状态怎么排”的问题，但还没有对 Koharu 里非常关键的 `BubbleIndex` 做独立复刻账本。

Koharu 的 `BubbleIndex` 不是简单 bbox：它从 bubble instance mask 计算每个气泡的 bbox、安全区、seed bbox 下的多数气泡 ID、最大安全布局区域，并在同气泡多文本块时保护 sibling layout。AITRANS 当前已有 BubbleMask proxy、mask-safe rect、safeLayoutRect、split candidate、reading order、render lock 和 BubbleMask assignment / split scoreboard，但这些证据还分散在多个报告里。

v1.35 应新增一个 report-only 的 `Koharu BubbleIndex Shadow Ledger`：

- 用 AITRANS 自己已有探针证据复刻 Koharu `BubbleIndex` 的核心决策账本。
- 对每个 block 解释：当前 `bubbleID` 是否稳定、是否与 proxy dominant bubble 冲突、当前 `safeLayoutRect` 与 shadow safe rect 是否一致、同气泡 sibling 分区是否有重叠 / 抢位 / 分割风险、渲染锁是否稳定。
- 对每个 bubble instance 解释：包含哪些 blocks、是否单块稳定、多块 sibling 稳定、需要 split review、assignment conflict，还是必须等待真实 BubbleMask artifact。
- 输出 shadow-only 的安全区 / sibling partition 对照，不应用到主覆盖图，不改 `safeLayoutRect`、不改 OCR、翻译、`blockPassed` 或渲染逻辑。

本轮应该比 v1.34 更具体：不是再列一个泛化候选矩阵，而是把 Koharu `BubbleIndex` 的多数 mask 归属、安全区、同气泡 sibling 分区和 render-safe gate 收束成可由 CI 检查的报告。
