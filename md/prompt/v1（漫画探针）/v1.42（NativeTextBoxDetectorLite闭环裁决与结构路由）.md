v1.40 已新增 `koharuNativeTextBoxDetectorLiteShadowOCRReport`：只消费 v1.39 `shadowOCREligible = true` 的 detector-lite 候选，执行受限 Vision crop OCR，输出 empty / failed / better / worse / same、quality delta、word preservation、evaluation-only ground truth similarity、block ledger 和 gate。

v1.41 已新增 `koharuNativeTextBoxDetectorLiteRefinementReport`：消费 v1.39 detector-lite 与 v1.40 shadow OCR ledger，在 detector-lite 父 bbox 内生成 refined bbox，并在预算内执行 refinement shadow OCR。

下一步不应做第三轮 crop / line / deskew / bbox 调参，也不应再单纯堆一个 Koharu 名字的解释报告。v1.42 要把 v1.39-v1.41 的 detector-lite 闭环结果收束成一个结构路由和裁决账本：逐块回答当前 TextBoxes native proxy 是应该停止、保留 report-only、full probe 复核、等待真实 TextBoxes / BubbleMask / SegmentMask，还是被模型地板或渲染锁主导。该账本必须使用 AITRANS 自己的探针输出分析 OCR 准确率、气泡归属 / 分割、翻译失败分类、覆盖渲染和结构瓶颈，但不能把 shadow OCR 结果写回主流程。

Koharu 源码确认的关键事实：

- `Artifact::TextBoxes`、`SegmentMask`、`BubbleMask`、`OcrText`、`RenderedSprites`、`FinalRender` 是一等 artifact，engine 通过 `needs` / `produces` 组织 DAG。
- `comic-text-detector-seg` 明确 `needs: [TextBoxes]`，先有 TextBoxes 再 refine SegmentMask。
- `paddle-ocr-vl-1.6` 明确 `needs: [TextBoxes]`，OCR 在每个 text node crop 上执行。
- `refine_segmentation_mask` 没有 TextBoxes 时会清空 mask，有 TextBoxes 时只保留扩张框内的文字像素，再膨胀并裁回框内。

因此 v1.42 的重点是让 AITRANS 的 native detector-lite 形成 Koharu 式 TextBoxes 阶段的 closed-loop gate，而不是把 Vision OCR / ground truth / 手写框伪装成真实 Koharu TextBoxes。

### 5. Stoplist 和 full-probe 复核规则
v1.42 必须显式输出 stoplist / review list，但只写报告。

建议规则：

- 若 v1.40 和 v1.41 均 empty / worse / same，且 block 主要瓶颈仍是 OCR 输入或 proxy mask 弱：`stopDetectorLiteLocalTuning` 或 `routeToRealTextBoxesArtifact`。

- 若 block failure 是 `modelOutputFailure` 或 `translationLanguageQualityFailure`，且 clean text / model floor 已证实模型地板：`routeToModelFloor`，不继续调 OCR。
