### 2. Bundle-Lite 组装算法要求
实现位置建议沿用 v1.43 / v1.44 风格，在 `MangaOverlayProbeService` 或 `TranslationSessionStore` 的私有 helper 中生成报告，不要把逻辑塞进 UI。

最低算法要求：

1. 每个 final block 必须有一条 `blockLedger`，即使上游报告缺失也要写 blocked / fallback 原因。
2. TextBox component 优先来自 v1.44 selected candidate 或 v1.39 detector-lite candidate；若只能退到 final block bbox，必须写 `componentSource = fallbackFinalBlockBBox` 和 `proxyNotRealKoharuTextBoxes = true`。
3. BubbleMask component 优先来自 v1.43 instance-lite majority；没有时可退到 current bubble geometry，但必须写 `componentSource = fallbackCurrentBubbleGeometry`。
4. SegmentMask component 优先来自 v1.44 selected refinement-lite candidate；没有时可退到 existing glyph / SegmentMask proxy summary，但必须写 fallback。
5. OCR component 只引用已有 final OCR、v1.40 / v1.41 shadow OCR outcome、closed-loop route和 quality delta；不得新增 OCR。
6. Translation component 只引用已有 failureCategory、translation decision trace、clean text / model floor 结论；不得新增 LLM。
7. Render component 只引用已有 safeLayoutRect、RenderSprite fit、Render Regression Lock、v1.43 / v1.44 containment；不得重新渲染。
8. Consistency edge 至少覆盖：
   - `TextBoxWithinBubble`
   - `SegmentMaskWithinTextBox`
   - `SegmentMaskWithinBubble`
   - `FinalOCRBBoxAlignedWithTextBox`
   - `SameBubbleSiblingMaskNonOverlap`
   - `SeamOrSplitRiskExplainsConflict`
   - `RenderSpriteContainedByBundleSafeArea`
   - `ModelFloorSeparatesGeometryFromTranslation`
9. 每条 edge 必须有 `status`、`severity`、`evidence`、`affectedBlocks`、`decisionSignals`、`evaluationSignals`，且 decision 不使用 ground truth。
10. 每个 block ledger 必须输出 `primaryBlockingArtifact`，稳定值建议：
    - `TextBoxes`
    - `BubbleMask`
    - `SegmentMask`
    - `OcrText`
    - `Translations`
    - `RenderedSprites`
    - `FinalRender`
    - `ExternalArtifacts`
    - `NoneReportOnlyConsistent`
    - `ManualReview`
11. 每个 block ledger 必须输出 `nextAction`，稳定值建议：
    - `readyForFullProbeShadowReview`
    - `keepMainFusedOCR`
    - `stopLocalGeometryTuning`
    - `collectRealTextBoxesArtifact`
    - `collectRealBubbleMaskArtifact`
    - `collectRealSegmentMaskArtifact`
    - `fixNativeTextBoxDetectorLite`
    - `fixNativeBubbleMaskInstanceLite`
    - `fixNativeSegmentMaskRefinementLite`
    - `modelFloorNoGeometryAction`
    - `renderLockNoOCRAction`
    - `manualReviewOnly`
12. workItems 要把 block-level nextAction 聚合为少量清晰队列，避免只输出 13 条重复建议。
