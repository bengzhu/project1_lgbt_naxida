## 本轮目标
从最新 `smalldata_test` 开分支：

```text
codeb/v1.26-bubblemask-assignment-split-scorecard
```

新增一个 AITRANS 自有探针驱动的 BubbleMask 归属分割评分板：

```text
bubbleMaskAssignmentSplitScoreboardReport
```

报告目标：

1. 执行 v1.24 推荐的 `WI-bubblemask-assignment-split-scorecard`。
2. 聚合 `bubbleMaskReport`、`bubbleAssignmentCorrectionReport`、`bubbleSplitCandidateReport`、`bubbleSubRegionReport`、`readingOrderStructureAuditReport`、`structureActionCandidateReport`、`koharuNativeReplicationScoreboardReport`、`nativeTextBoxProxyLedgerReport`、最终 `blocks` 和渲染诊断。
3. 对每个 block 输出 BubbleMask 归属状态、split / merge 风险、同气泡 sibling 布局状态、mask safe rect 和 render gate、是否需要真实 BubbleMask、下一步动作。
4. 对每个 bubble 输出实例级账本：包含 blocks、冲突块、split candidate、same-bubble sibling 布局、safe rect 覆盖和 forbidden promotion reasons。
5. 输出 report-level gate ledger，严格区分 ground-truth-free 决策信号和 evaluation-only 真值指标。

本轮仍是 report-only / diagnostic-only。不得改变主 OCR、翻译输入、覆盖图、`blockPassed`、失败分类、post-fusion cleanup、候选选择、`configuration.currentBlockSource`、`safeLayoutRect` 或 `metrics/version_history.csv` 口径。
