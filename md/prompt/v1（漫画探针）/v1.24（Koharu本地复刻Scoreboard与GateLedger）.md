## 本轮目标
从最新 `smalldata_test` 开分支：

```text
codeb/v1.24-koharu-native-scoreboard
```

新增一个 AITRANS 自有探针驱动的 Koharu 本地复刻评分板：

```text
koharuNativeReplicationScoreboardReport
```

报告目标：

1. 把 v1.23 的 stage gap / work package 计划转成可验收的 native scoreboard 和 gate ledger。
2. 明确本轮评估只依赖 AITRANS 自己的 probe 输出；真实 external artifact 缺失只作为一个可选外部路径状态，不阻塞 native 评分。
3. 对 Koharu canonical stage 逐项输出本地复刻状态、ground-truth-free 决策信号、evaluation-only 指标、gate 结果、下一步优先级。
4. 对每个 block 输出本地复刻 scorecard：OCR、气泡、SegmentMask proxy、翻译、渲染五类信号分别处于 pass / warning / blocked / stop 的哪种状态。
5. 输出推荐下一轮 work item 排序，避免 Agent B 继续在已证伪的 crop / line / deskew 试参上消耗。

本轮仍是 report-only / diagnostic-only。不得改变主 OCR、翻译输入、覆盖图、`blockPassed`、失败分类、post-fusion cleanup、候选选择、`configuration.currentBlockSource` 或 `metrics/version_history.csv` 口径。

阶段判断建议：

- `sourceImage` / `contentCrop`：应为 `nativeReady` 或 `renderStable`，只要裁切仍在 OCR 前。
- `nativeTextBoxes`：当前不是真实 Koharu detector，但可作为 `nativeProxyReady`；若 crop / line / deskew gate 全失败，应标出 `nativeStopTuning` 或 `shadowBlocked`。
- `nativeBubbleMask`：当前是 AITRANS proxy instance / mask-safe layout；有 conflict / split risk 时为 `nativeProxyReady` + `warning`，不是 `blocked` 除非影响主流程。
- `nativeSegmentMask`：glyph / connected component proxy；可用于渲染和报告，不可晋级 inpainting 或主 OCR。
- `ocrText`：如果 `textRegionCropReport.adoptedCount = 0`、crop / line promotion 均空，必须输出 `stopLocalTuning = true`。
- `translations`：clean text pass rate 低时标为 `modelLimited`，不要把端到端失败单独归因给 OCR。
- `renderedSprites` / `finalRender`：若无 overflow / truncation 且失败块仍绘制，标为 `renderStable`。

## 目标 3：Gate Ledger
新增 `gateLedger[]`，每条 gate 至少输出：

- `gateID`
- `gateName`
- `scope`
- `status`
- `requiredForMainFlowPromotion`
- `decisionSignals`
- `evaluationSignals`
- `threshold`
- `affectedBlocks`
- `failureMeans`
- `recommendedAction`
- `groundTruthUsedForDecision = false`

至少包含这些 gate：

- `G-no-main-flow-mutation`：本轮必须 `passed`。
- `G-no-ground-truth-decision`：候选生成、排序、promotion 和 cleanup 不读 ground truth，必须 `passed`。
- `G-native-textbox-word-preservation`：crop / TextBox / line shadow 候选不得丢 raw 关键词。
- `G-native-textbox-stoplist`：已被 `textBoxPlanFailureReport` 和 `lineCropExperimentReport` 判定 stop 的块，不再建议继续本地 crop / line / deskew 试参。
- `G-bubble-assignment-conflict`：气泡归属 / 分割冲突只能进 shadow / report，不能跨气泡合并。
- `G-segment-mask-inside-bubble`：glyph / segment proxy 不得越出所属气泡；不能当真实 Koharu SegmentMask。
- `G-clean-text-model-floor`：clean text pass rate 低时，翻译失败需保留 model-limited 分类。
- `G-render-failure-overlay`：失败块必须仍绘制 `翻译失败 + OCR 原文`。
- `G-render-no-overflow`：成功和失败块都不能倒置、镜像、截断或越界。
- `G-external-artifact-optional`：缺真实 artifact 是 optional external path，不阻塞本报告；但不能把 proxy 说成真实 Koharu artifact。

Gate 语义必须稳定：

- `status = stop` 表示本地试参方向应停止，不代表主流程坏。
- `status = externalOptionalMissing` 表示真实 Koharu artifact 不存在，但本轮 native scoreboard 仍可完成。
- `requiredForMainFlowPromotion` 对所有会影响主流程的 gate 必须为 `true`；本轮不执行 promotion。
