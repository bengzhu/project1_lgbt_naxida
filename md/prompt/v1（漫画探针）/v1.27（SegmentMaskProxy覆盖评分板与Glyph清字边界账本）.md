## 本轮目标
从最新 `smalldata_test` 开分支：

```text
codeb/v1.27-segmentmask-proxy-coverage-scorecard
```

新增一个 AITRANS 自有探针驱动的 SegmentMask proxy 覆盖评分板：

```text
segmentMaskProxyCoverageScoreboardReport
```

报告目标：

1. 执行 v1.24 推荐的 `WI-segmentmask-proxy-coverage-scorecard`。
2. 聚合 `segmentMaskReport`、逐块 glyph mask 字段、`textBoxCandidateReport`、`bubbleMaskReport`、`bubbleMaskAssignmentSplitScoreboardReport`、`nativeTextBoxProxyLedgerReport`、`koharuNativeReplicationScoreboardReport`、最终 `blocks` 的背景填充和渲染碰撞证据。
3. 对每个 block 输出 SegmentMask proxy 覆盖状态、glyph 清字安全状态、TextBox / BubbleMask / safe rect 覆盖、背景填充资格、render mask collision、是否弱 segment、是否需要真实 SegmentMask、下一步动作。
4. 输出 glyph cleanup ledger：明确哪些块只可用于 report-only cleanup evidence、哪些块可作为渲染清字边界证据、哪些块必须阻塞，因为 glyph 缺失、逃出 TextBox、逃出 BubbleMask、safe rect 覆盖低、decorative / unassigned 或 proxy 证据不足。
5. 输出 report-level gate ledger，严格区分 ground-truth-free 决策信号和 evaluation-only 真值指标。

本轮仍是 report-only / diagnostic-only。不得改变主 OCR、翻译输入、覆盖图、`blockPassed`、失败分类、post-fusion cleanup、候选选择、`configuration.currentBlockSource`、`safeLayoutRect`、`glyphMaskFillRects`、背景填充行为或 `metrics/version_history.csv` 口径。
