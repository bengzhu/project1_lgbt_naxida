### 2. Target selection 要求
每个最终 block 都必须有 block ledger，但只有满足条件的 block 执行 refined OCR。target 选择只能使用 ground-truth-free 信号。

优先 target：

- v1.40 `shadowOutcome` 为 `emptyOCR`、`ocrFailed`、`worseThanCurrent` 或 `sameAsCurrent`，但 v1.39 detector-lite candidate 有足够 bubble / glyph / block relation 证据。
- block `failureCategory = ocrInputSuspect`，且不是 translation model floor 主导。
- v1.40 `wordPreservationVsCurrent` 低，或 refined bbox 可能通过投影 / 连通域收紧改善。
- Bubble / Segment proxy 显示候选过大、候选越过气泡、glyph overlap 弱、candidate bbox 明显包含大量非文字暗像素。

跳过或仅记账：

- block 已 `blockPassed = true` 且 render lock 稳定。
- `failureCategory` 明确是 `modelOutputFailure` 或 `translationLanguageQualityFailure`，应路由到 model floor，不做 OCR 调参。
- v1.40 已 `betterThanCurrent` 且无明显 bbox 风险，v1.41 不需要再二次 OCR，记录 `keepDetectorLiteShadowOCRReportOnly`。
- 缺 v1.39 / v1.40 report 时输出 blocked report，不崩溃。

禁止：

- 不得因为 `ocrGroundTruthSimilarity` 低而选择 target。
- 不得因为 ground truth 文本能解释某个框就生成 bbox。
- 不得读取旧 `output/probe_report.json` 里的字段决定本轮 runtime target。

### 3. Refined candidate 生成要求
refined bbox 必须以 v1.39 `nativeDetectorLite` candidate bbox 为父框。建议实现 3-5 个轻量策略，按每块最多 1 个 ci-fast 候选选择 best ground-truth-free candidate：

- `trimToDarkComponentEnvelope`：在 source candidate bbox 内做暗像素阈值 / 连通域 envelope，剔除大面积空白和明显非文字边缘。
- `projectionBandTighten`：按 `directionHint` 做水平 / 垂直投影峰，收紧文字带；横排主要收 y，竖排主要收 x。
- `directionalPaddingByHint`：按 `horizontal / vertical / unknown` 用不同 padding，保守扩张文字带，避免切字。
- `bubbleSafeClip`：如果当前 bubbleID 和 BubbleMask proxy 证据一致，将 refined bbox clamp 到 bubble bbox / mask-safe rect 内；冲突时只记录 blocker，不强行 clip。
