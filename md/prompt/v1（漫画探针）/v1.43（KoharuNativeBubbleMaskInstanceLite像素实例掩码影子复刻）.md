v1.43 要把 BubbleMask 方向从 rounded-rect proxy 往源图像像素生成的 instance-lite ID mask 推进一步：在漫画探针中新增一个 shadow-only 的 `koharuNativeBubbleMaskInstanceLiteReport`。它只用 `test/1.png` 内容区像素、现有 bubble candidates / bubble geometry、final blocks、glyph / SegmentMask proxy、BubbleIndex / DistanceField / seam / RenderSprite / detector-lite closed-loop 证据，生成逐实例 mask 账本、逐块 majority-ID 归属账本、safe rect 对照和结构瓶颈路由。

这不是接入真实 Koharu `BubbleMask`，也不能冒充外部 artifact。它是 AITRANS 本地算法复刻：从像素生成更接近 Koharu `BubbleMask` 语义的 report-only instance-lite mask 证据，为后续真实 BubbleMask、清字、渲染 containment 和 TextBox crop 约束做准备。
