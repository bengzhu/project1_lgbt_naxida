## 本轮目标
从最新 `smalldata_test` 开分支：

```text
codeb/v1.18-internal-structure-routing
```

本轮做一个小步、可验证、可回退的算法结构优化：在 AITRANS 自有探针内部建立 Koharu 式“结构瓶颈路由”报告，并用它驱动一处保守的 post-fusion 重复/碎片清理改进。

目标分两层。

### 目标 1：新增内部结构瓶颈路由报告
新增一个报告层，建议命名为：

```text
internalStructureBottleneckReport
```

它不是外部 artifact，不依赖 `test/koharu_artifacts/`，不替换主流程文本。它要把现有报告中已经分散的证据聚合成可执行路由，帮助后续版本决定应该优化哪一层：

```text
OCR block
  -> TextBox / SegmentMask / BubbleMask proxy evidence
  -> fusion / post-fusion cleanup status
  -> crop / line / shadow OCR blockers
  -> translation failure category
  -> render / overlay status
  -> recommendedNextAction
```

每个 block 至少输出：

- `blockIndex`
- `groundTruthMatch`
- `groundTruthType`
- `ocrGroundTruthSimilarity`
- `wordOrderPreserved`
- `bubbleID`
- `bbox`
- `finalTextUsedForTranslation`
- `failureCategory`
- `blockPassed`
- `primaryBottleneck`
- `secondaryBottlenecks`
- `recommendedNextAction`
- `evidence`
- `mustNotPromoteReasons`

建议 `primaryBottleneck` 使用稳定枚举字符串：

- `ocrCharacterDamage`
- `duplicateOrFragment`
- `bubbleAssignmentOrSplit`
- `cropCandidateBlocked`
- `modelTranslationQuality`
- `renderOnly`
- `passed`
- `externalArtifactOptionalMissing`
- `unknown`

建议 `recommendedNextAction` 使用稳定枚举字符串：

- `tryPostFusionFragmentSuppression`
- `improveTextBoxOrSegmentEvidence`
- `improveBubbleSplitOrAssignment`
- `keepMainTextAndDoNotTuneGeometry`
- `tryPromptOrModelComparison`
- `renderNoAction`
- `noActionPassed`
- `noActionExternalArtifactOptional`
- `manualReview`

报告级至少汇总：

- `evaluatedBlockCount`
- `primaryBottleneckBreakdown`
- `recommendedActionBreakdown`
- `dialogueBottleneckBreakdown`
- `decorativeBottleneckBreakdown`
- `ocrInputSuspectBlocks`
- `duplicateOrFragmentBlocks`
- `modelTranslationQualityBlocks`
- `cropCandidateBlockedBlocks`
- `bubbleSplitOrAssignmentBlocks`
- `renderOnlyBlocks`
- `passedBlocks`
- `notes`

关键规则：

- ground truth 只能用于报告评估和路由归因，不得用于生产候选选择、排序、清理或晋级。
- `externalArtifactReadinessReport.readinessVerdict = manifestMissing` 只能归为 `externalArtifactOptionalMissing` 或 report note，不能成为主线阻塞。
- 报告必须从现有明细现场计算，不能硬编码 block index 结果。
- 报告必须出现在 `probe_report.json`；`1_ocr_probe_text.txt` 每块也要有一行瓶颈摘要。
- `ci-fast` 必须保留该报告，不得只在 full 模式生成。

### 目标 2：保守改进 post-fusion 重复/碎片清理
在 `fusedWholePageBubble` 后的 post-fusion cleanup 中，增加一条保守的重复/碎片拒绝规则，优先处理当前 block 10 / 11 这类情况：

```text
两个或多个 fused blocks 命中同一 bubble 或强重叠邻域，
文本存在明显 token 子集/重复关键词关系，
较小候选信息量低、符号/乱码比例高、词数少或被更完整候选覆盖，
且拒绝它不会删除受保护关键文本，
则把较小候选标为 duplicateOrFragment 并从主 blocks 中剔除。
```

实现要求：

- 只能使用 ground-truth-free 信号：bbox overlap / containment、bubbleID、文本 token 覆盖、文本长度、词数、符号比例、OCR 质量启发、fusion source、confidence、是否保护关键文本。
- 不得读取 `test/1.ground_truth.json` 来决定保留或删除。
- 必须保护这些文本不被误删：
  - `Let's Battle!`
  - `What are you even talking about?`
  - `We need to get results at this tournament to save the gaming club from being disbanded.`
  - `The City Battler Tournament starts in a few days.`
- 不允许为了提高指标跨气泡合并。
- 不允许删除 decorative 标题，只因为它像重复或短文本。
- 被拒绝块必须进入 `fusionComparison.postFusionCleanup.rejectedBlocks`，写明 `rejectionReason = duplicateOrFragment` 或更具体原因、`relatedKeptBlockIndex`、`qualityScore`、`protectedTextMatched=false` 等证据。
- 如果没有任何块满足保守规则，也要在报告中写明 evaluated / no-op 结果，不要为了变化而强行删除。

预期收益：

- 若 block 11 被安全识别为 block 10 的碎片，`totalBlocksDetected` 可能从 `13` 降到 `12`，重复匹配 `Or at least...` 的问题会减少。
- 如果云端 OCR 波动导致不满足保守条件，也允许 no-op；本轮仍应通过新增瓶颈路由报告提供价值。

## 实现提示
建议按这个顺序实现：

1. 在 `AITRANS/Models/TranscriptModels.swift` 新增 `MangaOverlayInternalStructureBottleneckReport`、block summary 和必要的 enum-like string 字段。
2. 在 `TranslationSessionStore.runMangaOverlayProbe` 已生成 fusion、crop、TextBox、SegmentMask、BubbleMask、translation diagnostics 后，调用一个纯汇总函数生成 `internalStructureBottleneckReport`。
3. 在 `MangaOverlayProbeReport` 中加入该 report 字段，并保证 JSON 编码向后兼容。
4. 在 `MangaOverlayProbeService` 的 TXT 报告生成里，每块追加：

```text

```

5. 在 post-fusion cleanup 函数里增加保守 duplicate/fragment 规则，尽量复用已有 `postFusionInformationScore`、保护文本和 rejection report 结构。
6. 更新 `README.md`、`md/flow/flow.md`、`md/flow/flowchart.md`、`md/test/test.md`、`update_log.md` 中受影响的当前流程说明。

瓶颈分类建议：

- `blockPassed = true`：`primaryBottleneck = passed`，`recommendedNextAction = noActionPassed`。
- decorative 且 OCR 相似度高：优先不要归为 OCR 主瓶颈；可写 `renderOnly` 或 `passed`。
- `failureCategory = modelOutputFailure` 或 clean text 同类句也失败：优先 `modelTranslationQuality`。
- OCR similarity 低、`failureCategory = ocrInputSuspect`、候选含明显错词/符号：`ocrCharacterDamage`。
- 同 bubble / 邻域内存在短碎片、重复关键词、低信息量：`duplicateOrFragment`。
- `textBoxPlanFailureReport` 或 crop / line shadow 显示 better-than-control 但被 blockers 挡住：`cropCandidateBlocked`。
- BubbleMask inconsistent、split candidate、oversized bubble、assignment correction 风险明显：`bubbleAssignmentOrSplit`。
- external artifact 缺失：只记 optional note，不盖过 OCR / bubble / model 的真实瓶颈。
