## 本轮目标
从最新 `smalldata_test` 开分支：

```text
codeb/v1.23-koharu-stage-gap-replication
```

新增一个 Koharu 阶段差距复刻计划报告：

```text
koharuStageGapReplicationReport
```

报告目标：

1. 以 Koharu canonical pipeline 为参照，对齐 `SourceImage / TextBoxes / SegmentMask / BubbleMask / OcrText / Translations / Inpainted / RenderedSprites / FinalRender` 等阶段。
2. 从 v1.22 `koharuArtifactDAGReport`、v1.21 `structureActionCandidateReport`、v1.18-v1.20 结构报告和最终 `blocks` 中抽取证据。
3. 输出每个阶段的当前 AITRANS 能力、复刻差距、需要的最小输入、可执行的下一步 work package、晋级 gate 和停止条件。
4. 为每个 block 输出最小升级路径：当前首次阻塞阶段、应补的 artifact / 算法、是否受 OCR、气泡分割、翻译模型或渲染约束。
5. 明确哪些工作可以用 `ci-fast` 的现有输出验证，哪些必须等 `full` 探针或真实 external artifact。

本轮仍是 report-only / diagnostic-only。不得改变主 OCR、翻译输入、覆盖图、`blockPassed`、失败分类、post-fusion cleanup、候选选择、`configuration.currentBlockSource` 或 `metrics/version_history.csv` 口径。

- `textBoxes`：当前多为 `aitransProxyOnly` 或 `missingExternalArtifact`；输入来自 `textBoxCandidateReport`、`preCropTextBoxPlanReport`、`cropExperimentReport`、`externalArtifactReadinessReport`。

- `renderedSprites` / `finalRender`：当前已有 safe layout、离屏碰撞和失败块绘制，应把渲染问题和 OCR/翻译问题分开。

建议 work package 类型：

- `WP-textboxes-real-artifact-gate`：等待真实 `test/koharu_artifacts/` 四件套，不创建假 artifact。
- `WP-bubblemask-instance-validation`：把当前 BubbleMask proxy 与归属/分割风险整理成真实 mask 接入后的验证目标。
- `WP-segmentmask-glyph-coverage-gate`：定义文字像素 mask 晋级前必须满足的覆盖、越界和 crop blocker gate。
- `WP-ocr-crop-stoplist`：把已证明无收益的 crop / line / deskew 试参列入停止清单，避免继续消耗。
- `WP-render-safe-area-retain`：保留已工作的 safe layout / collision / failure overlay，避免后续 OCR 改动破坏覆盖。
- `WP-translation-model-comparison`：只作为未来模型对比包，不能在本轮更换模型或改主 prompt。

`expectedMetricMovement` 必须分清：

- OCR 准确率：核心看可信匹配后的 dialogue / decorative 相似度。
- 气泡归属 / 分割：看 bubble conflict、split risk、same-bubble siblings、post-fusion cleanup。
- 翻译失败分类：看 `failureCategory`、`cleanTextDiagnostic` 和 strict prompt 对照，不只看 CJK 字符。
- 覆盖渲染：看 safe layout、render overflow、truncation、失败块是否绘制。

## 目标 5：Promotion Gate 语义
新增 `promotionGates[]` 或在 stage / work package 内嵌 gate。每个 gate 至少输出：

- `gateName`
- `scope`
- `requiredForPromotion`
- `currentStatus`
- `evidence`
- `threshold`
- `affectedBlocks`
- `failureMeans`
- `groundTruthUsedForDecision = false`

建议 gate：

- `noMainFlowMutation`：本轮必须始终通过。
- `noGroundTruthPlanning`：候选生成、排序、选择、promotion 不读 ground truth。
- `realArtifactReadiness`：只有 active artifact ready 才能进入 external TextBoxes shadow OCR。
- `protectedTextRetained`：`Let's Battle!`、`What are you even talking about?`、`We need to get results...` 等关键内容不能被 cleanup 误删。
- `wordPreservationGuardrail`：crop / line / external shadow 不得丢 raw 关键词。
- `noIntroducedLikelyOCRError`：不能用看似更短但损坏专有名词的 OCR 候选。
- `bubbleConflictResolved`：气泡归属 / 分割候选不得跨气泡合并。
- `segmentInsideBubble`：glyph / segment 证据不得跑出所属气泡。
- `renderNoOverflow`：失败块和成功块都必须可绘制、不可倒置、不可静默跳过。
- `cleanTextModelFloor`：clean text 仍低时，不把端到端失败单独归因给 OCR。
