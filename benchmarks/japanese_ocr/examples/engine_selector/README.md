# v3.285 selector contract example

`input.json` is synthetic and deliberately blocked. It demonstrates that the
bundled Manga OCR engine is retained for every block when the candidate artifact
is missing, the feature flag is disabled, or cancellation/duplicate/stale-budget
guards fire.

The fixture is not a benchmark and contains no ground truth. Its runtime text
is only a non-empty/empty output signal. It must not be used to claim OCR
quality, candidate eligibility, license clearance, or product rollout.
